# Codebase Context Clipper 📋

A VS Code extension that helps you enhance AI prompts by easily extracting codebase context. Clip folder structures as tree-like formats and extract code interfaces to provide accurate context for your LLM conversations.

## Deprecated

**This extension is no longer maintained and is deprecated.**

Since its original release, AI capabilities have significantly evolved and become increasingly integrated into modern IDEs. Features that once required dedicated extensions, such as extracting codebase context for LLM prompts, are now largely handled natively by AI-powered development tools.

As a result, this extension is no longer necessary and will not receive further updates.
